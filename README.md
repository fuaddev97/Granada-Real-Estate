# Granada Real Estate

A modern and immersive real estate website for **Granada Real Estate**, built with React, TypeScript, Vite, and vanilla CSS.

The project focuses on creating a premium editorial-style experience with bold typography, large imagery, smooth animations, and responsive layouts.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Full-screen animated hero section
- Smooth scroll and reveal animations
- Interactive property showcase
- Continuous scrolling marquee
- Editorial-style typography and layouts
- Animated navigation and hover effects
- Responsive mobile navigation
- Contact/enquiry section
- Accessible reduced-motion support
- Custom UI built entirely with vanilla CSS

## 🛠️ Built With

- **React**
- **TypeScript**
- **Vite**
- **Vanilla CSS**
- **HTML5**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/granada-real-estate.git
```

Navigate to the project:

```bash
cd granada-real-estate
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will then be available at the local development URL provided by Vite.

## 📦 Build for Production

Create a production build with:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎨 Design

The website takes inspiration from modern luxury real estate websites, combining:

- Large editorial imagery
- Minimal and sophisticated navigation
- Strong typography
- Spacious layouts
- Subtle luxury-inspired colors
- Motion and interaction to create a more engaging experience

The design was developed specifically for **Granada Real Estate** rather than being a direct copy of another website.

## 📱 Responsive Design

The website is designed to provide a consistent experience across:

- Desktop
- Laptop
- Tablet
- Mobile devices

Layouts, typography, navigation, imagery, and animations adapt to different screen sizes.

## 🎯 Purpose

This project was created as a modern real estate website concept demonstrating how a property brand can combine **visual storytelling, strong branding, and interactive web experiences**.
